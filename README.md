# Tris imbattibile con Minimax

Gioco Tris (Tic-Tac-Toe) in Python con intelligenza artificiale imbattibile, basata sull'algoritmo Minimax. Interfaccia a riga di comando.

## Tecnologie
- Python 3
- Solo librerie standard, nessuna dipendenza esterna

## Come funziona
L'algoritmo Minimax esplora ricorsivamente tutti gli scenari di gioco per scegliere la mossa ottimale. L'IA è imbattibile: nel peggiore dei casi pareggia.
